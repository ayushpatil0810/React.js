# React.js Practice Projects ⚛️

This repository contains a collection of small projects and experiments I built while learning **React.js**. Each folder demonstrates different React concepts and features implemented through hands-on practice.

---

## 📚 About

While learning React, I built several mini-projects to understand how different parts of the framework work. These projects helped me practice building reusable components, managing state, handling routing, and working with modern React tools.

---

## 📂 Projects Included

* **Counter App** – Basic state management using `useState`
* **Background Color Changer** – Dynamic UI updates with React state
* **Card Components** – Reusable components using props
* **Currency Converter** – Data handling and calculations
* **Investment Calculator** – Simple financial calculation app
* **Password Generator** – Random password generation with React hooks
* **React Router Demo** – Navigation using React Router
* **Redux Toolkit Example** – State management using Redux Toolkit
* **Theme Switcher** – Light/Dark theme toggle
* **Todo App** – Todo management using Context API and Local Storage
* **Tailwind Props Example** – Styling components with Tailwind CSS

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/ayushpatil0810/React.js.git
cd React.js
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
